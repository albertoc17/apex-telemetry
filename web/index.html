APEX / DRIVE WITH DATA.

PC → WI-FI → IPAD / IPHONE

Conectar por IP

En el PC abre Iniciar APEX.cmd. Verás una IP: escribe ese mismo número aquí. El PC y el móvil deben estar en la misma red.

Al conectar se abre el dashboard local de tu PC. Con el modo Wi-Fi no necesitas token ni túnel.
También puedes usar el modo protegido local con dirección HTTP y token, si ya abriste el panel local.

Preparar cada juego

DiRT Rally 2.0: activa UDP en el archivo del juego con destino 127.0.0.1:20777 y extradata="3". Esa es la conexión juego → puente en el PC; la IP que introduces en el móvil es la IP Wi-Fi del PC.

Euro Truck Simulator 2: instala y ejecuta Funbit Telemetry Server y su plugin. APEX lee sus datos en el PC.

El modo Wi-Fi permite que dispositivos de tu red privada lean la telemetría. Usa una red de confianza. Para mantener la página de GitHub Pages abierta con datos reales, usa la conexión avanzada HTTPS.
