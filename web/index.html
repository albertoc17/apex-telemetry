Conexión y pantalla

Conecta el iPad o iPhone al Wi-Fi del PC desde Ajustes de iOS. Aquí configuras el puente de telemetría.

Incluye http:// o https:// y el puerto, si corresponde.Se conserva únicamente en esta pestaña.

Cómo conectar DiRT y Euro Truck
  1. En el PC instala Node.js 22 o superior y descarga este proyecto desde GitHub.
  2. Ejecuta npm start. Copia el token de la terminal.
  3. DiRT: configura UDP a 127.0.0.1:20777 con extradata="3". Euro Truck: instala y ejecuta el servidor Funbit y su plugin.
  4. Desde GitHub Pages usa una dirección HTTPS con certificado confiable. Puedes usar el túnel HTTPS explicado en el README.
  5. Para una conexión local sin túnel, abre en Safari la dirección Wi-Fi que imprime el puente (por ejemplo http://192.168.1.20:8787).

La página HTTPS de GitHub Pages no puede consultar un puente HTTP. Si no conecta, revisa token, origen permitido, certificado, firewall y acceso de Safari a la red local.
